# Gtrack Backend (FastAPI)

Deployed on Hugging Face Spaces (Docker SDK).
This is the API for the Gtrack asset-tracking application.

- Base URL: `https://<your-username>-<space-name>.hf.space`
- Docs:     `https://<your-username>-<space-name>.hf.space/docs`
- API v1:   `https://<your-username>-<space-name>.hf.space/api/v1`

> When you create the Space, **rename this file to `README.md`** (replacing the existing one)
> so Hugging Face picks up the metadata block above.
